# Ermias Mekonnen - Backend Developer Portfolio

A modern, responsive portfolio website showcasing the skills and experience of Ermias Mekonnen, a passionate backend developer specializing in NestJS, Laravel, and microservices architecture.

## Features

- **Modern Design**: Clean, minimalist design inspired by contemporary portfolio sites
- **Dark/Light Theme**: Toggle between dark and light themes with smooth transitions
- **Responsive Layout**: Fully responsive design that works on all devices
- **Interactive Elements**: Custom cursor, smooth scrolling, and engaging animations
- **Performance Optimized**: Lightweight and fast-loading with optimized assets

## Sections

- **Hero**: Eye-catching introduction with animated code block
- **About**: Personal information and key statistics
- **Experience**: Professional timeline with detailed work history
- **Education**: Academic background and certifications
- **Skills**: Technical expertise organized by categories
- **Contact**: Contact form and information

## Technologies Used

- **HTML5**: Semantic markup for better accessibility
- **CSS3**: Modern styling with CSS Grid, Flexbox, and custom properties
- **JavaScript**: Interactive features and smooth animations
- **Font Awesome**: Icons for enhanced visual appeal
- **Google Fonts**: Inter font family for clean typography

## Key Features

### Theme System
- Persistent theme selection (stored in localStorage)
- Smooth transitions between themes
- Dynamic icon updates

### Custom Cursor
- Interactive cursor that responds to hover states
- Disabled on mobile devices for better UX

### Smooth Animations
- Scroll-triggered animations using Intersection Observer
- Typing animation for the hero title
- Counter animations for statistics
- Timeline animations for experience section

### Navigation
- Sticky navigation with scroll effects
- Active section highlighting
- Mobile-responsive hamburger menu
- Smooth scrolling to sections

### Form Handling
- Contact form with validation
- Success/error notifications
- Loading states for better UX

## Browser Support

- Chrome (latest)
- Firefox (latest)
- Safari (latest)
- Edge (latest)

## Performance Features

- Optimized animations using `requestAnimationFrame`
- Throttled scroll events for better performance
- Lazy loading of animations
- Efficient DOM manipulation

## Customization

The website uses CSS custom properties (variables) for easy theming:

```css
:root {
    --bg-primary: #ffffff;
    --text-primary: #1e293b;
    --accent-primary: #3b82f6;
    /* ... more variables */
}
```
